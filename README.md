# 🏏 IPL Data Analytics Dashboard

An interactive Power BI dashboard created to analyze IPL 2025 statistics, team performance, and player insights using real-world cricket data.

# Dataset used

-<a href= "https://github.com/Nimishaa6/IPL-2025-Data-Analytics-Dashboard/blob/main/players-data-updated.csv"> Players data updated</a>
-<a href= "https://github.com/Nimishaa6/IPL-2025-Data-Analytics-Dashboard/blob/main/ipl_matches_data.csv"> IPL matches data</a>
-<a href= "https://github.com/Nimishaa6/IPL-2025-Data-Analytics-Dashboard/blob/main/teams_data.csv"> IPL team data </a>

# 📊 Key KPIs

The dashboard includes the following KPIs:

- Total Matches
- Total Teams
- Total 4s
- Total 6s
- Total Centuries
- Total Half Centuries
- Orange Cap Winner
- Purple Cap Winner
- Points Table Rankings
- Team-wise Performance Statistics
