# 🏏 IPL Data Analytics Dashboard

An interactive Power BI dashboard created to analyze IPL 2025 statistics, team performance, and player insights using real-world cricket data.

# Dataset used

-<a href= "https://github.com/Nimishaa6/IPL-2025-Data-Analytics-Dashboard/blob/main/players-data-updated.csv"> Players data updated</a>
-<a href= "https://github.com/Nimishaa6/IPL-2025-Data-Analytics-Dashboard/blob/main/ipl_matches_data.csv"> IPL matches data</a>
-<a href= "https://github.com/Nimishaa6/IPL-2025-Data-Analytics-Dashboard/blob/main/teams_data.csv"> IPL team data </a>

# 📊 Key KPIs

The dashboard includes the following KPIs:

- Total Matches
- Total Teams
- Total 4s
- Total 6s
- Total Centuries
- Total Half Centuries
- Orange Cap Winner
- Purple Cap Winner
- Points Table Rankings
- Team-wise Performance Statistics

# ⚙️ Project Process

## 1. Data Collection
Collected IPL 2025 data from online cricket datasets and CSV files.

## 2. Data Cleaning
Performed data cleaning using:
- Removed null values
- Fixed inconsistent team/player names
- Formatted tables properly

## 3. Data Transformation
Used Power Query to:
- Transform raw data
- Create relationships
- Prepare structured datasets

## 4. Data Modeling
Built relationships between:
- Matches table
- Players table
- Teams table

## 5. DAX Calculations
Created DAX measures for:
- Total Runs
- Total Wickets
- Boundaries
- KPIs
- Rankings

## 6. Dashboard Development
Designed an interactive dashboard using:
- Cards
- Tables
- Filters
- Team visuals
- KPI sections

## 7. Insights Generation
Generated insights related to:
- Best performing teams
- Top players
- Season statistics
- Match trends

# 📈 Project Insights

- Mumbai Indians and Royal Challengers Bengaluru showed strong overall performance during the season.
- The dashboard helped identify the top-performing batsmen and bowlers using Orange Cap and Purple Cap statistics.
- Teams with higher boundary counts (4s & 6s) generally achieved better match results.
- Interactive filters made it easy to compare team and player performance across the tournament.
- KPI analysis provided quick insights into total matches, centuries, half-centuries, and overall season statistics.
- Data visualization improved the understanding of team rankings and match trends.
- The project demonstrated how sports data can be transformed into meaningful business insights using Power BI.
- Dashboard interactivity helped users analyze performance efficiently and make data-driven observations.
